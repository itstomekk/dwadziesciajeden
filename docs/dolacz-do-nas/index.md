# Dołącz do nas

Jeśli szukasz ludzi z którymi mógłbyś:

- podyskutować o bieżących wydarzeniach,

- zasięgnąć porady lub konsultacji,

- otworzyć kanał Lightning

- sprawdzić swoje memy przed publikowaniem,

- zorganizować meetup,

- zrobić jakiś Proof-of-Work dla społeczności (artykuły, kod, poradniki, ...),

- poszukać optymizmu zamiast pobiadolić o upadku cywilizacji,

- ostrzec przed scamem, etc...
