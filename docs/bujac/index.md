# Bujać!

Bo nikt nam nie może zabronić. Polskie rozmowy o pieniądzu, wolności i budowaniu poza systemem: Bitcoin, NOSTR, prywatność i własne drogi komunikacji.

Obraz: Okładka podcastu Bujać!

Autor: **Mateusz Gadaj**. Zaprzyjaźniony projekt i dobre miejsce, żeby posłuchać Polaków, którzy żyją na standardzie Bitcoina. Tu zebraliśmy wszystkie 18 odcinki w jednym miejscu.
