# Deltabadger

Polskie narzędzie do automatycznego, regularnego kupowania bitcoina (DCA) na wybranej giełdzie.

Obraz: Grafika: Deltabadger

Deltabadger to narzędzie do automatycznego inwestowania. Projekt udostępnia kod źródłowy i pozwala uruchomić program na własnym serwerze.

Można za jego pomocą ustawić regularne zakupy bitcoina na obsługiwanej giełdzie. Program łączy się z kontem giełdowym za pomocą kluczy API.
