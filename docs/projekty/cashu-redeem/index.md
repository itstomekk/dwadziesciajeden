# Cashu Redeem

Prosta strona do wymiany tokenów Cashu, czyli prywatnej cyfrowej gotówki opartej na bitcoinie, na satsy przez Lightning Address albo LNURL. Napisana od zera przez kogoś z naszej społeczności, dziś w oficjalnym repozytorium Cashu.

Obraz: Zrzut ekranu: Cashu Redeem

Cashu Redeem to aplikacja internetowa do wymiany tokenów Cashu na środki w portfelu Lightning. Jej otwarty kod znajduje się w repozytorium organizacji Cashu na GitHubie.

W aplikacji można wkleić token oraz podać Lightning Address lub LNURL. Autorzy repozytorium ostrzegają, że projekt może zawierać błędy prowadzące do utraty środków.
